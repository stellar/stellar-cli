---
title: Contract Lifecycle
description: Manage the lifecycle of a Stellar smart contract using the CLI
---

To manage the lifecycle of a Stellar smart contract using the CLI, follow these steps:

<Steps>

<Step title="Set your preferred network">

This guide uses `testnet`. See [Networks](/docs/networks) for the list of available networks.

```bash
stellar network use testnet
```

</Step>

<Step title="Create an identity for Alice">

```bash
stellar keys generate alice -q
```

</Step>

<Step title="Fund the identity">

```bash
stellar keys fund alice
```

</Step>

<Step title="Deploy a contract">

```bash
stellar keys use alice
```

```bash
stellar contract deploy --wasm /path/to/contract.wasm --alias mycontract
```

This displays the resulting contract ID, for example:

```text
CBB65ZLBQBZL5IYHDHEEPCVUUMFOQUZSQKAJFV36R7TZETCLWGFTRLOQ
```

To learn more about how to build contract `.wasm` files, take a look at our [getting started tutorial](/docs/build/smart-contracts/getting-started/setup).

</Step>

<Step title="Invoke a contract function">

```bash
stellar contract invoke --id mycontract -- <FUNCTION>
```

</Step>

<Step title="View the contract's state">

```bash
stellar contract read --id mycontract --durability <DURABILITY> --key <KEY>
```

`<DURABILITY>` is either `persistent` or `temporary`. `<KEY>` is the key of the storage entry being read.

</Step>

<Step title="Extend the TTL of the contract's state">

```bash
stellar contract extend --id mycontract --ledgers-to-extend 1000 --durability <DURABILITY> --key <KEY>
```

This extends the TTL of the storage entry with the given key to at least 1,000 ledgers from the current ledger.

</Step>

</Steps>
