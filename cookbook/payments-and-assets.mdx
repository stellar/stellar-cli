---
title: Payments and Assets
description: Send XLM and other Stellar assets using the Stellar CLI
---

To send payments and work with assets using the Stellar CLI, follow these steps:

1. Set your preferred network. This guide uses `testnet`. See [Networks](/docs/networks) for the list of available networks.

```bash
stellar network use testnet
```

2. Fund the accounts:

```bash
stellar keys generate alice
```

```bash
stellar keys fund alice
```

```bash
stellar keys generate bob
```

```bash
stellar keys fund bob
```

3. Get the contract ID of the native asset's Stellar Asset Contract:

```bash
stellar contract id asset --asset native
```

4. Get Bob's public key:

```bash
stellar keys address bob
```

5. Send 100 XLM from Alice to Bob:

```bash
stellar keys use alice
```

```bash
stellar contract invoke --id <ASSET_CONTRACT_ID> -- transfer --to bob --from alice --amount 100
```

6. Check Bob's balance:

```bash
stellar contract invoke --id <ASSET_CONTRACT_ID> -- balance --id bob
```

For more information on the functions available on the Stellar Asset Contract, see the [token interface code](/docs/tokens/token-interface#code).
