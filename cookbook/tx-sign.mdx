---
title: tx sign and tx send
description: Sign and submit transactions with the Stellar CLI's tx sign and tx send commands
---

The previous `tx new` examples created transactions, then signed and submitted them to the network right away.

To stop before signing, each subcommand has a `--build-only` argument, which only builds the transaction and prints the transaction envelope.

## `tx sign`

Return to the first example of creating `bob`'s account:

```sh
stellar tx new create-account \
  --source alice \
  --destination bob \
  --starting-balance 100_000_000 \
  --build-only
```

This outputs something like:

You can also sign the transaction with the `tx sign` command. To do this, pipe the output of the `tx new` command to the `tx sign` command:

```sh
stellar tx new create-account \
    --source alice \
    --destination bob \
    --starting-balance 100_000_000 \
    --build-only \
  | stellar tx sign --sign-with-key alice
```

<Tip>

You can also sign with Stellar Lab. For now, you must send the transaction from Lab, because it can't return the signed transaction to the CLI.

```sh
stellar tx new create-account \
    --source alice \
    --destination bob \
    --starting-balance 100_000_000 \
    --build-only \
  | stellar tx sign --sign-with-lab
```

</Tip>

## `tx send`

Finally, to submit the transaction to the network, use the `tx send` command:

```sh
stellar tx new create-account \
    --source alice \
    --destination bob \
    --starting-balance 100_000_000 \
    --build-only \
  | stellar tx sign --sign-with-key alice \
  | stellar tx send
```
