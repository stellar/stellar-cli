---
title: Extend a deployed contract instance's TTL
description: Use the CLI to extend the time to live (TTL) of a contract instance
---

You can use the Stellar CLI to extend the TTL of a contract instance like so:

```bash
stellar contract extend \
    --source S... \
    --network testnet \
    --id C... \
    --ledgers-to-extend 535679 \
    --durability persistent
```

This example extends the TTL by 535,679 ledgers, roughly 30 days at an average ledger close time of 5 seconds. The network's `max_entry_ttl` setting caps this value, and the CLI returns an error if you ask for more.

When you extend a contract instance, this includes:

- the contract instance itself
- any `env.storage().instance()` entries in the contract
- the contract's Wasm code
